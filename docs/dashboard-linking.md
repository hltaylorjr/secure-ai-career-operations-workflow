# Professional dashboard integration checklist

The GitHub account can be linked from the professional dashboard after the following conditions are satisfied:

- GitHub display name and biography are professional and current
- Profile image and visual identity are appropriate for public career use
- Account email visibility is intentionally configured
- Two-factor authentication is enabled
- The portfolio repository has passed a secret and personal-information scan
- The repository description, topics, README, rights notice, and third-party acknowledgments are complete
- The repository is made public only after an explicit final approval
- The dashboard link points to the public GitHub profile or approved public repository
